## Jalview

Jalview 是一款免费的跨平台程序，用于多序列比对的编辑、可视化和分析。您可以使用它进行序列比对、查看和编辑比对结果，通过系统发育树和主成分分析（PCA）图进行分析，并探索分子结构及注释信息。
